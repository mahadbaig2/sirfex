# Security Policy

## Scope

SIRFEX runs trusted local Python controllers and simulation code. It is not a sandbox for untrusted code and does not provide safety certification for real systems.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Contact the repository owner privately through GitHub with a description, reproduction steps, affected version, and potential impact. Do not include credentials, tokens, or other secrets in reports.

The local API and future Studio must remain bound to localhost and must not expose arbitrary code execution as a hosted service.
